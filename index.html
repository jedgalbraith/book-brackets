About This Project

Book Brackets is an interactive visualization tool that helps readers understand the structural and thematic relationships within Book of Mormon chapters. By drawing visual brackets around related passages, it provides insights into how different chapters connect thematically.

Features

  • Interactive bracket visualization
  • Multiple topic perspectives (Locations, Events, Timeline, Visions)
  • Clickable chapters linking to full scripture text
  • Rich chapter descriptions and context
  • Responsive design for all devices

Built with D3.js • Book of Mormon Study Tool
